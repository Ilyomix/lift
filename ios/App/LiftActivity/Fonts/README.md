`DSEG7ClassicMini-BoldItalic.ttf` is the unmodified DSEG v0.46 font from
https://github.com/keshikan/DSEG/releases/download/v0.46/fonts-DSEG_v046.zip.

It matches the face used by the app's web timer. The extension bundles the font
and the existing `src/assets/fonts/DSEG-LICENSE.txt` (SIL Open Font License 1.1).
